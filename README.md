# TLI FAQ — тир-листы Torchlight: Infinite

Сайт: https://evgeniyshes.github.io/TLIFAQ/

- `index.html` — страница (вёрстка и логика)
- `data.js` — все данные: герои, тир-листы, билды, изменения сезона, источники. Чтобы обновить тиры, правь этот файл.
- `img/` — портреты героев (источник: tlidb.com)
