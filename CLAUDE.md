# TLIFAQ
Сайт тир-листов Torchlight: Infinite (tlifaq.pages.dev, деплой из `main`).
- Перед работой прочитать `README.md` (файлы, правила, как обновлять тиры и добавлять билды, API tlicompendium) и `SOURCES.md` (что уже проверено — не перепроверять).
- После крупного обновления содержимого — запись в `changelog` в `data.js`: только EN, кратко; SEO и мелкая вёрстка — нет, заметные улучшения удобства — да.
- Данные правятся только в `data.js` (тексты RU+EN), потом `node build.js` и коммит вместе со сгенерированными файлами.
